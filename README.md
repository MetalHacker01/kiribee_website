# Kiribee — Brand Website

Hand-poured Albanian beeswax candles. Built on Next.js 15 + TypeScript + Tailwind, deployed on Vercel.

## Local development

```bash
npm install
npm run fetch-images   # one-time: downloads top-9 IG images into public/images/
npm run dev            # http://localhost:3000  →  redirects to /en
```

The first request loads the English locale by default. Visit `/sq` for Albanian.

## Project layout

- `app/[locale]/page.tsx` — homepage (single page, anchor-driven sections)
- `app/[locale]/layout.tsx` — locale-aware shell, sets `<html lang>`, mounts JSON-LD
- `app/api/contact/route.ts` — POST handler that delivers form messages via Resend
- `app/index.md/route.ts`, `app/home.md/route.ts` — root-level markdown copy of the page
- `app/[locale]/index.md/route.ts`, `app/[locale]/home.md/route.ts` — per-locale markdown
- `app/llms.txt/route.ts` — AI-agent discovery file
- `app/opengraph-image.tsx` — generated 1200×630 OG image
- `lib/content.ts` — single source of truth for site copy and brand facts
- `lib/markdown.ts` — generates the `.md` route bodies from the same source as the UI
- `lib/seo.ts` — metadata + JSON-LD helpers
- `messages/{en,sq}.json` — i18n strings consumed by next-intl
- `components/sections/*` — Hero, Story, Benefits, Process, FeaturedCandles, Gallery, Contact, Footer
- `components/motion/*` — Reveal, SmoothScroll (Lenis), Flame
- `scripts/fetch-ig-images.mjs` — pulls top-liked photos from `../posts.json`

## Deploy to Vercel

1. Push this folder to a GitHub repo.
2. In Vercel: **New project** → import the repo → keep defaults (Next.js auto-detected).
3. Add environment variables:

   | Variable                | Value (example)                                       |
   |-------------------------|-------------------------------------------------------|
   | `NEXT_PUBLIC_SITE_URL`  | `https://kiribee.com`                                 |
   | `RESEND_API_KEY`        | from <https://resend.com/api-keys>                    |
   | `RESEND_FROM`           | `Kiribee <noreply@mail.kiribee.com>` (verified sender) |
   | `CONTACT_TO`            | `kiribeecom@gmail.com`                                |

4. Add the custom domain `kiribee.com` in Vercel → Settings → Domains.
5. Add Vercel's DNS records to your registrar.

## Resend setup

1. Sign up at <https://resend.com>.
2. **Domains** → add `mail.kiribee.com` (subdomain of your purchased domain). Resend will give you DKIM/SPF DNS records — paste them into your domain registrar.
3. **API keys** → create one with permission "Sending access only" → paste it into Vercel as `RESEND_API_KEY`.
4. Send a test email through the contact form. The user's email is set as the `Reply-To`, so Ana/Aldo can hit reply directly in Gmail.

## Replacing placeholder content

Open `lib/content.ts` and update the values flagged with `// TODO`:

- **`SITE.facebook`** — confirmed Facebook page URL
- **`SITE.whatsapp`** + **`SITE.whatsappDisplay`** — real WhatsApp number with country code

When you have professional photography, drop hi-res files into `public/images/` and overwrite the placeholders with the same filenames (`candle-beequite.jpg`, `candle-honeycomb.jpg`, `candle-embrace.jpg`, `candle-personalized.jpg`, plus `gallery/01.jpg`–`09.jpg`). No code changes needed.

## SEO surface

- Per-locale `<title>` / `<meta description>`, OG, Twitter card via App Router metadata API.
- Hreflang `en` / `sq` / `x-default`.
- JSON-LD: `Organization`, `LocalBusiness` (Tirana, AL), `WebSite`, and one `Product` per featured candle.
- Sitemap at `/sitemap.xml` (generated by `next-sitemap` on `postbuild`).
- AI-agent feeds at `/index.md`, `/home.md`, `/llms.txt`, plus per-locale variants.

## Verifying everything works

```bash
npm run dev
# In another terminal:
curl -I http://localhost:3000/index.md         # Content-Type: text/markdown
curl    http://localhost:3000/llms.txt         # AI agent index
curl -I http://localhost:3000/sq               # 200, locale layout
```

Then submit the contact form once with `RESEND_API_KEY` set and verify the email lands in `kiribeecom@gmail.com`.
